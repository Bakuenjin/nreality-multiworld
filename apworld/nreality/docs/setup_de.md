# NReality Multiworld: Einrichtung

## Voraussetzungen

- MultiworldGG
- `nreality.apworld`
- Eine eigene Kopie von NReality 6g2: `NReality6g2.zip` von [n.infunity.com](https://n.infunity.com/). Spieldateien werden nicht verteilt.

## Installation

1. `nreality.apworld` doppelklicken (oder „Install APWorld“ im MultiworldGG-Launcher).
2. **NReality Client** im Launcher starten. Der Browser öffnet die Spielseite.
3. Nur beim ersten Start: `NReality6g2.zip` auf der Seite auswählen. Der Client baut daraus das Spiel und lädt einmalig
   den Flash-Emulator Ruffle herunter (Internet nötig). Sonst muss nichts installiert werden.

## Spielen

In der Konsole rechts mit `/connect <adresse>` verbinden und den Slotnamen eingeben oder auf der Raumseite den eigenen
Slot anklicken. Spielfläche anklicken, „play game“ und eine offene Episode wählen. Ausgegraute Nummern sind noch
gesperrte Episoden des Seeds. Chat, `!hint` und die übrigen Befehle laufen über dieselbe Konsole.

Levelabschlüsse bleiben im Browser gespeichert, bis der Server sie bestätigt, und überstehen so Verbindungsabbrüche.

## Generieren

Wer die Multiworld generiert, braucht nur die `.apworld`, nicht das Spiel. Das erzeugte Archiv auf multiworld.gg
hochladen, um es zu hosten.
